# WANAKRIYA — Laravel Web Application Portfolio

**Independent Web Development Project | Work in Progress**

## Project Overview

WANAKRIYA is a business-oriented web application developed using PHP and Laravel with a modular monolith architecture.

The project explores how a web-based platform can support product management, commerce transactions, and business operations through an organized and maintainable application structure.

This project is part of my independent learning and hands-on development experience in software engineering.

## Tech Stack

- **Backend:** PHP, Laravel
- **Frontend:** Blade Templates, HTML, CSS, JavaScript, Vite
- **Database:** SQL / Relational Database
- **Architecture:** MVC, Modular Monolith
- **Development Environment:** Laragon, Visual Studio Code
- **Development Tools:** Composer, npm, Git, GitHub

## Core Features

The application includes development work on:

- Product catalog and category management
- Shopping cart and session-based data handling
- Checkout and order processing
- Server-side input validation
- Administrative functionality and access management
- Database integration and application testing

Features are being developed and refined incrementally.

## Application Architecture

WANAKRIYA adopts a modular monolith approach, organizing related business functionality into separate modules while maintaining a single Laravel application.

The architecture is intended to support separation of responsibilities, code organization, and maintainability as application features expand.

## Development and Testing

Development activities include:

- Implementing application features using Laravel MVC components
- Working with routing, controllers, models, and database operations
- Reviewing application logic and debugging issues
- Conducting functional and automated testing
- Using AI-assisted development tools for implementation support, troubleshooting, and continuous learning
